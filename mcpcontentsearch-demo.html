Personal Project · Retrieval & MCP

ContextWiki

A private MCP server for LLM agents — with RAG-style retrieval over your own notes. Syncs Notion, Tistory, GitHub, and Obsidian through a durable sync worker into a dual store — Chroma for semantic search, SQLite for lifecycle metadata — then returns citation-backed context so answers stay grounded.

The plot

01
The mess

Four silos. Zero shared search.

Notes lived in Notion, GitHub, Obsidian, and a blog — useful alone, useless when an agent needed one grounded answer across all of them.

Notion GitHub Obsidian Tistory
02
The dual store

Chroma finds. SQLite decides what’s still live.

Embeddings surface similar chunks; SQLite owns jobs, tombstones, and the active-document check so deleted pages cannot keep citing themselves.

semantic hit active-document check tombstones
03
The long sync

Jobs leave the chat. Re-syncs stay fast.

MCP tools only enqueue work; a durable sync worker claims SQLite jobs outside the request path. Unchanged documents skip fetch so re-syncs do not redo the whole vault.

enqueue → claim skip unchanged exact job_id
04
The payoff

An agent asks. Cited chunks answer first.

Eight MCP tools cover sync, status, search, and date browse. Evidence shows up in-thread — before the final prose — already filtered by the active-document check.

in-thread retrieval search_context list_documents
